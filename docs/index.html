How a battle works

A debate, not a side-by-side. Each round builds on the last.

1

Answer alone

Every AI answers your question without seeing the others.

2

Argue

They read each other's answers, rebut the weak points, concede the good ones, and revise.

3

Judge blind

They score each other as "Debater A, B, C" on accuracy, reasoning, engagement and calibration. Nobody scores itself.

Why battler

Built for people who already pay for more than one AI.

Uses what you already pay for

Runs through each vendor's official tool: Claude Code, Codex, Cursor and Gemini CLI, signed in with your plans. API keys are stripped, so nothing is billed per token.

Fair, blind judging

Labels are shuffled every battle, every AI judges, self-scores are thrown out, and the score comes from a fixed checklist rather than a judge's gut.

Web app, terminal and Chrome

A local web app with live progress and history, a fast terminal tool, and a beta Chrome extension that drives the chat websites in your own tabs.

Local and yours

Everything runs on your Mac. Every battle is saved as a file you own, and you can ask a follow-up or add a round any time.

Get started

Two minutes, if you already use two of these AIs.

npm install -g battler
battler setup   # checks your AI tools, helps sign in, runs a test battle
battler serve   # opens the web app
# or right in the terminal
battler "Is it still worth learning to code in 2026?"
# no install: just compare their answers side by side
npx battler -c "Best way to learn SQL?"

Questions

Is it free?

battler is free and open source (MIT). The debates run on your existing Claude, ChatGPT and Cursor subscriptions, and count against their normal limits. A standard battle with three AIs is about 9 messages spread across your plans.

Do I need API keys?

No, and it won't use them: battler removes API keys from the environment before starting each AI tool, so every call goes through your subscription.

Which AIs does it support?

Claude (via Claude Code), GPT (via Codex CLI), Grok (via Cursor), and Gemini (via Gemini CLI) if you have it. If you only have Cursor, it can play every part. You need at least two debaters.

How is the winner decided?

Each AI rates the others 1-5 on accuracy, reasoning, engagement and calibration, without knowing who's who and without scoring itself. battler averages the ratings, and the top of the scorecard wins. Treat scores as informed opinion; the answer and the points of agreement are the most useful part.

Is this allowed by the AI providers?

The terminal and web app call each vendor's official command-line tool in its documented non-interactive mode. The Chrome extension automates the chat websites, which is a grey area in most providers' terms; it only acts when you start a battle, and its copy & paste mode avoids automation entirely. You're responsible for using your accounts within their terms.

Does it work on Windows or Linux?

macOS and Linux, both tested on every change. Windows isn't supported yet.
